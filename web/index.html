    La API

    Un solo endpoint. La foto se analiza en memoria y no se guarda. El código está en GitHub, con los tests y el Dockerfile. 

    curl -X POST "https://TU-API/api/paletas?n=6&modo=vivos" \
  -F imagen=@atardecer.jpg
    n
    Cuántos colores devolver, de 2 a 12. Por defecto, 6.
    modo
    presentes ordena por píxeles; vivos busca los colores que se recuerdan.
    Errores
    ProblemDetail (RFC 9457) en español: 400, 413, 422, 429 y 503.
